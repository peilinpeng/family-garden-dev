# 字体来源

客户端 UI 使用 Fusion Pixel Font 的简体中文 12px 比例字体。它沿用 Ark Pixel Font 的
基础字形与度量，并补齐项目实际文案和 AI 动态文本所需的常用汉字：

- 文件：`fusion-pixel-12px-proportional-zh_hans.ttf`
- 项目：https://github.com/TakWolf/fusion-pixel-font
- 版本：2026.09.01
- 发布包 SHA-256：`cf607641a61c721cd58409fa58a1ccf432e97d9ad25e76687948fa3027246fee`
- 字体文件 SHA-256：`1b423de0be589d159ef71af7d00530a7176e16af768a26adbc2e524e8817aad9`
- 许可：SIL Open Font License 1.1；完整主许可证与上游许可证位于
  `licenses/fusion-pixel-font-2026.09.01/`

字体随 Web 导出打包，用于保证浏览器环境稳定显示中文，并与 soft pixel art 视觉保持一致。

原 Ark Pixel 字体保留在仓库中用于历史构建复现，不再作为当前 UI 默认字体。
