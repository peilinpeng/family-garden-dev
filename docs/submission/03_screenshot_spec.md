# 03｜核心截图规范

## 输出规格

- 原始捕获：1280×720 PNG，与 Godot 逻辑画布一致；
- 平台要求 1920×1080 时使用最近邻放大，保持 16:9，不拉伸、不使用手机外框装饰；
- 浏览器缩放 100%，隐藏地址栏以外的无关 UI；
- 同一组截图使用一致的角色、名字和家庭数据；
- 不出现调试日志、文件路径、真实家庭照片或身份凭证；
- 仓库内单张建议不超过 1.2 MB，保留清晰文字和像素边缘。

## 选择原则

最终提交 6 张时，优先 `01/03/04/06/07/08`；提交 9 张时使用完整组。第一张必须是世界
本身，不能把表单或架构图作为封面。截图之间要呈现“空间、AI、家庭共享”三种不同信息，
避免连续多张都只是米色面板。

## 可选说明文字

- 花园：家庭记忆不只被存储，也会在共同空间中长成可探索的景观。
- 记忆卡片：AI 只整理用户提供的内容，并用温和问题邀请家人继续讲述。
- 记忆藤蔓：跨时间的家庭片段被关联起来，关系由家人补写和确认。
- 语义房间：AI 识别物件与区域，Godot 使用受控素材库生成安全可玩的房间。
- 共享农场：同一个家庭共同照料一块地，在线成员会收到实时刷新。
- 漂流瓶：低压力的问题入口，让家庭对话自然发生。

## 视觉复核

- 文字没有裁切、重叠或超出面板；
- 鼠标没有遮住标题和人物；
- loading、错误提示和 toast 不与底部导航重叠；
- 截图亮度和色彩一致，不使用会破坏像素边缘的锐化滤镜；
- 文件按编号排序，打开缩略图时也能看出每张的主题。
