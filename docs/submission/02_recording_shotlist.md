# 02｜录屏镜头表

## 主镜头

录制前在 Web 地址后添加 `?demo_hour=14`，避免系统时间导致同一组镜头明暗不一致。

| 编号 | 时长 | 必须拍到 | 通过标准 |
|---|---:|---|---|
| S01 | 6s | 花园全景、玩家、记忆花、底部入口 | 首帧没有弹窗，画面稳定，项目世界一眼可读 |
| S02 | 12s | 角色选择、显示名字、家庭邀请码 | 输入内容不含真实隐私，角色卡完整入镜 |
| S03 | 12s | “家人”面板 | 至少两位成员或清晰的成员状态，不暴露 token |
| S04 | 35s | 打开“记忆”、选择照片、输入文字、loading | 鼠标不乱晃，loading 和状态文案可读 |
| S05 | 20s | AI 草稿、来源、确认 | 卡片内容完整，确认前后差异清楚 |
| S06 | 16s | 新记忆花生长并打开卡片 | 生长反馈完整，卡片不遮挡关键内容 |
| S07 | 20s | 记忆藤蔓详情与补写入口 | 两端记忆、关系标签、追问同时可读 |
| S08 | 38s | 房间照片、语义网格、确认、生成房间 | 明确表现“识别语义 → 受控生成” |
| S09 | 28s | 农场种植与另一成员刷新 | 玩家走近地块，操作成功提示完整 |
| S10 | 25s | 鱼塘漂流瓶、回答、岸边记忆 | 问题、回答和结果形成连续镜头 |
| S11 | 18s | 花园/房间/农场/鱼塘蒙太奇 | 每个场景至少稳定停留 2 秒 |
| S12 | 8s | 花园全景与项目名 | 收尾干净，可放口号和团队信息 |

## 补拍镜头

- B01：AI 真实来源与模型信息特写；
- B02：上传失败后“不带照片保存”的恢复路径；
- B03：共享农场“家人的农场更新已同步”提示；
- B04：手机竖屏旋转提示；
- B05：桌面和手机横屏各一段 5 秒操作；
- B06：记忆藤蔓补写后“家人已补写”状态；
- B07：房间内书桌、台灯、植物和照片墙的语义锚点。

## 录制检查

- 每段镜头前后多录 2 秒，给剪辑留余量；
- 同一操作失败后停止录制，恢复状态再重拍，不把调试过程混入正式素材；
- 旁白后配，现场只保留低音量游戏声音；
- 每拍完一个镜头立即按 `S01_花园全景_take01` 格式命名；
- 每个关键镜头至少保留两个 take；
- 不录入终端、开发工具、云控制台和系统文件路径。

## 剪辑验收

- 前 20 秒出现问题和产品定位；
- 60 秒内第一次明确展示 AI；
- 150 秒内展示“AI 不输出坐标”的差异化设计；
- 210 秒内展示家庭共享与实时性；
- 最后 20 秒回到产品价值，不以技术列表结束；
- 字幕字号在手机全屏播放时仍可读，且不遮挡底部导航和状态提示。
