# 62｜M2 Web 发布包瘦身与资源完整性验收

> 日期：2026-08-02
>
> 分支：`feature/quality-optimization`
>
> 状态：已完成实现与本地验收

## 1. 目标与范围

M2 在不删除源码资源、不改主场景和不改变运行时功能的前提下，缩小 Web Release 的 PCK，
并为动态加载资源建立可重复的导出完整性检查。

本阶段只修改 Web 导出边界和本地验收工具：

1. 保留 `all_resources` 模式，避免 Godot 静态依赖分析遗漏运行时拼接路径；
2. 排除测试、开发工具、沙盒场景和已确认未接入当前主流程的旧资源包；
3. 新增一条命令完成 Release 导出、体积门禁、动态资源清单和导出包启动检查；
4. 不删除任何已有资源，后续若重新接入旧场景，只需调整 preset 排除规则即可恢复。

本阶段不处理 WASM 自定义模板、纹理重新压缩、音频重编码、资源图集合并或 CDN 分包；这些
操作会影响兼容性或画面/音质，应在独立阶段以浏览器和真机数据为依据实施。

## 2. 导出策略

项目存在多类运行时动态资源：

- `SceneManager` 通过字符串路径切换花园、农场、鱼塘、厨房和个人房间；
- 角色外观由 JSON manifest 组合图片路径；
- 背景音乐和音效通过目录扫描发现；
- 房间物件、记忆藤蔓和场景资产由 JSON 配置加载。

因此 M2 不切换到只导出主场景静态依赖的激进模式，而是在全量资源模式上做有证据的排除。
当前排除范围：

| 范围 | 原因 |
|---|---|
| `tests/*` | 本地回归场景与脚本，不属于生产运行时 |
| `tools/*` | 截图、素材生成与同步工具，不属于生产运行时 |
| `scenes/garden_builder/test/*` | 花园地形开发测试场景 |
| `scenes/Fishpond.tscn`、`assets/fishpond/*` | 已被 `scenes/pond/pond_area.tscn` 与 `assets/pond/*` 取代 |
| `scenes/GardenTiledSandbox.tscn` | 花园沙盒场景，不在当前场景路由中 |
| `assets/tilemap/*` | 旧 TileMap 素材包，当前运行时代码、场景与 manifest 无引用 |
| `assets/kitchen_ai/*` | AI 设计参考图，不由客户端运行时加载 |

排除前已在生产脚本、当前场景、配置和 manifest 中检查 `res://` 引用；被排除项仍完整保留在仓库。原 `assets/tilemap_gardening/*` 因第三方许可禁止再分发，已在后续 P1 审查修复中从工作树删除，不再依赖导出排除规则；功能分支历史清理需在修复提交后单独执行。

## 3. 可重复验收

执行：

```bash
./tools/check_web_export.sh
```

脚本要求 Godot 4.7 和已安装的 Web 导出模板，并验证：

1. `index.html`、`index.js`、`index.wasm`、`index.pck` 均成功生成且非空；
2. PCK 不超过 `130000000` bytes；
3. 主场景、五个动态场景、动态节点 prefab、公开配置和关键 manifest 均出现在导出清单；
4. 角色、农场、花园、厨房、鱼塘、音乐和音效动态目录均出现在导出清单；
5. 生产脚本、当前场景、配置和 manifest 没有重新引用任何排除项；
6. 所有生产排除项均未出现在导出清单；
7. Godot 可以挂载 PCK、启动主场景并在 180 帧内无脚本或资源加载错误。

如确有经过评审的新增生产资源导致 PCK 超限，可临时使用
`WEB_EXPORT_MAX_PCK_BYTES` 复核，并在确认原因后同步更新默认上限和本文件基线。成功产物默认清理；
设置 `KEEP_WEB_EXPORT=1` 可保留临时导出目录。

## 4. 体积结果

同一台 macOS arm64 设备、Godot 4.7 stable、Web Release preset 下实测：

| 指标 | M2 修改前 | M2 修改后 | 变化 |
|---|---:|---:|---:|
| `index.pck` | 132,943,264 bytes | 128,473,164 bytes | -4,470,100 bytes（-3.36%） |
| `index.wasm` | 39,509,339 bytes | 39,509,339 bytes | 0 |
| `index.js` | 279,815 bytes | 279,815 bytes | 0 |
| `index.html` | 9,878 bytes | 9,878 bytes | 0 |
| 核心四文件合计 | 172,742,296 bytes | 168,272,196 bytes | -4,470,100 bytes（-2.59%） |

M0 文档记录的 PCK 为 132,935,156 bytes；M2 开始前重新导出为 132,943,264 bytes，差异来自
M1 后的客户端变更。本表使用 M2 当次同代码、同环境的修改前后结果，避免跨提交比较造成误差。

## 6. 已知边界

1. 启动检查覆盖入口场景和初始化链路，不等同于浏览器端完整 E2E；
2. 审计通过导出清单验证动态资源存在，不会逐一实例化全部角色组合和美术资源；
3. PCK 优化不会改变固定 WASM 运行时体积；WASM 缩减需要自定义导出模板和跨浏览器测试；
4. 新增动态路径或重新启用旧场景时，必须同步更新 preset 与审计清单；
5. 当前体积门禁用于阻止无说明回退，不代表最终性能预算。
