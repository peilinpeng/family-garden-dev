## 1. 验收边界

本轮只覆盖单设备手机 Web：

- 竖屏启动时显示旋转提示，并阻断底层误触；
- 旋转到横屏后恢复原有游戏状态，不刷新、不黑屏；
- 浏览器照片选择器支持 PNG、JPEG、WebP，取消后不残留全屏输入层；
- 选中照片后，文件名、MIME 和字节内容能交给 Godot。

已明确延期的“双设备、双账号真实 UI 联机验收”不在本轮范围内。

## 2. 本轮发现与修复

全新浏览器第一次进入游戏时，开场剧情使用独立 `CanvasLayer(layer=30)`，原旋转提示只是
`UIRoot` 下的高 `z_index` 控件。`z_index` 无法跨 CanvasLayer 覆盖开场剧情，因此竖屏会看到
被缩小的剧情卡，而不是清晰的旋转提示。

修复后，旋转提示位于独立 `OrientationLayer(layer=100)`：

- 竖屏时覆盖开场剧情和常驻 HUD；
- 横屏时隐藏，原开场剧情仍停留在旋转前的状态；
- 不修改剧情、存档、云端或照片业务逻辑。

## 5. 真机最终点检（约 2 分钟）

使用一台真实 iPhone Safari 或 Android Chrome，并准备一张不含隐私的测试图片：

1. 通过 HTTPS 打开验收地址并点“进入家庭花园”，确认入口不会显示“暂时无法进入”；
2. 竖屏进入，应只看到完整的“请旋转手机”；
3. 旋转到横屏，应回到开场剧情或原游戏画面，无刷新、黑屏、重复启动；
4. 再竖屏、再横屏一次，确认状态仍保留；
5. 进入花园后点“创建记忆”，再点“选择照片（可选）”；
6. 先取消一次，相册关闭后游戏应立即可操作；
7. 再选一张 PNG/JPEG/WebP，界面应显示“已选择：文件名（大小）”；
8. 不需要提交记忆，可直接取消，避免写入业务数据。

验收记录只需填写：设备型号、系统版本、浏览器版本、横竖屏恢复是否通过、取消是否通过、
照片文件名/大小是否回显。截图不得包含真实家庭照片、token 或内部 ID。
