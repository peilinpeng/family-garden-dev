## 环境恢复选择

1. 登录后若原环境与数据仍存在，先核实套餐／路由／托管故障原因，导出配置清单和恢复前备份；需费用时提供可审阅方案后确认。
2. 若已经迁移，验证新环境 ID、路由、数据与旧发布记录的对应关系，再统一配置和部署；不能只改一个 URL 宣称完成迁移。
3. 若原环境不可恢复，先核查现有备份可恢复范围，再设计新环境；禁止用演示种子冒充恢复出的真实数据。
