# 55｜Gate 4 视觉资产与首屏体验验收

更新：2026-07-09
分支：`feature/gate4-visual-experience-polish`

## 1. 本轮目标

这轮把 Gate 4 从“功能可用”推进到“第一眼能看懂、核心 AI 物件有生命感”。

不改 AI 契约、不改数据结构、不改后端，只打磨场景层和 UI 表层：

- 花园、鱼塘、玩家房间进入后有轻量状态卡；
- 记忆花、漂流瓶、AI 房间物件有统一的 soft pixel 光晕、阴影和轻微脉冲；
- 记忆藤蔓从普通连线升级为带叶片、脉冲和补写盛开状态的关系视觉；
- 房间照片预览从纯文字清单升级为“布局小地图 + 家具清单”；
- 底部导航和关键入口文案统一为中文。

## 2. 覆盖范围

| 模块 | 升级内容 |
|---|---|
| 首屏 HUD | 顶部文案、底部导航、世界聊天输入中文化 |
| 花园入口 | 显示记忆花、记忆藤蔓、家庭画像版本 |
| 鱼塘入口 | 显示漂流瓶、岸边记忆、鱼塘藤蔓 |
| 玩家房间 | 显示 AI 房间状态与物件数 |
| 动态节点 | 记忆花光晕、漂流瓶水波、AI 家具标记 |
| 记忆藤蔓 | 叶片、脉冲、高亮、已补写盛开标记 |
| 房间预览 | 布局小地图、区域中文名、家具中文名 |

## 3. 人工验收步骤

1. 进入花园，确认左上状态卡不遮挡玩家、房屋或核心交互。
2. 查看记忆花：新记忆显示“待回应”，已回答记忆显示“已确认”，节点有光晕和入场动画。
3. 点击记忆藤蔓，确认藤蔓有叶片和脉冲；补写后再次进入场景，藤蔓显示盛开标记。
4. 进入鱼塘，确认漂流瓶有水波/阴影，状态卡能显示漂流瓶和岸边记忆数量。
5. 点击漂流瓶，确认问题面板有水面色带，回答提示清楚。
6. 进入玩家房间，确认房间入口卡显示 AI 房间状态；已有房间时按钮为“管理 AI 房间”。
7. 上传房间照片并进入预览，确认布局小地图和家具清单都可读。
8. 在 1280×720 逻辑画布下检查：状态卡、面板、按钮、标签不重叠。

## 5. 已知边界

- 本轮没有引入外部新美术文件，节点增强通过程序化 soft pixel 贴图完成；
- 房间预览小地图是产品预览，不代表最终美术场景透视；
- 非玩家房间仍保持原有静态房间体验；
- Web 端真实照片选择仍需导出 Web 包后人工点检。
