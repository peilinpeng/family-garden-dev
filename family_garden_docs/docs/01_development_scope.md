# 01｜开发边界与优先级

## 1. 本文档目的

本文档用于控制 Family Garden 的开发范围，避免项目在有限时间内因为想法过多而失焦。

所有成员在开发任何新功能前，都必须先判断：

> 这个功能是否服务于家庭记忆、家庭交流或共同参与？

如果不能，就不应优先进入比赛版本。

---

## 2. 本次比赛版本的核心目标

比赛版本不是完整商业产品，而是一个能够稳定展示核心价值的参赛 Demo。

核心目标：

```text
上传一段家庭记忆
↓
AI 整理成记忆卡片
↓
AI 提出温和问题
↓
家庭成员回答
↓
游戏地图生成记忆节点
↓
家庭花园逐渐生长
```

只要这条主线完整、稳定、好理解，项目就有竞争力。

---

## 3. P0：必须完成

P0 是比赛版本必须完成的内容。任何 P0 不稳定，都比新增 P1/P2 更严重。

### 3.1 核心功能

| 功能 | 说明 | 验收标准 |
|---|---|---|
| 进入家庭花园 | 用户进入主场景 | 手机横屏和桌面网页都能打开 |
| 上传照片/记忆 | 用户上传照片、房间图或文字 | 上传后能创建一条 memory 记录 |
| AI 记忆卡片 | AI 生成标题、描述、问题、推荐场景、节点类型 | 输出 JSON 可被游戏读取 |
| 用户回答问题 | 用户对 AI 问题进行补充 | 回答能保存并显示 |
| 地图生成节点 | 根据 AI 输出生成记忆花/照片牌/漂流瓶等节点 | 节点可点击，能打开卡片 |
| 家庭花园场景 | 主 Hub | 至少包含记忆花、入口牌、漂流瓶入口 |
| 爸爸鱼塘场景 | 漂流瓶与家庭问题 | 可进入、可打开漂流瓶、可回答 |
| AI 房间生成展示 | 上传房间图后生成相似氛围房间 | 至少识别并展示 3 个房间物件 |
| 记忆卡片 UI | 展示 AI 结果 | 文字清晰、按钮可点、可关闭 |
| 失败兜底 | AI/上传失败时可继续演示 | 有 mock 数据和预设案例 |

---

## 4. P1：强加分项

P1 用于增强项目特色，但不能影响 P0 的稳定性。

| 功能 | 价值 | 进入条件 |
|---|---|---|
| 爷爷农场 | 长辈故事、记忆种子 | P0 跑通后开发 |
| 老街/胡同/弄堂 | 童年、老家、祖辈记忆 | 至少有基础背景和 2 个点击点 |
| 旅行区域 | 家庭旅行、明信片 | 作为明信片节点展示即可 |
| 记忆树 | 多段记忆汇总 | 可先做成静态成长展示 |
| 轻微动画 | 水面、光点、节点成长 | 不影响性能和稳定性 |
| 家庭成员头像 | 标明是谁上传/回答 | UI 上简单展示即可 |

---

## 5. P2：时间充足再做

P2 不进入比赛核心承诺，可以作为后续发展方向。

- 更多家庭成员个人空间；
- 妈妈花房；
- 节日广场；
- 多城市记忆地图；
- 更多角色动作；
- 更复杂的房间装饰；
- Android APK；
- PWA 桌面安装体验优化；
- 更多 AI 故事整理方式。

---

## 6. 本次明确不做

为了避免项目失焦，本次比赛阶段明确不做：

1. 战斗系统；
2. 打怪系统；
3. 开放世界冒险；
4. AI 恋爱 NPC；
5. 复杂人物养成；
6. 商店和装修商城；
7. 多人实时聊天；
8. 高精度 3D 房间重建；
9. AI 心理分析；
10. AI 擅自编造家庭事实；
11. 大型多人在线同步；
12. 商业化支付功能。

---

## 7. 功能降级规则

如果时间不足，按以下顺序降级：

### 7.1 场景数量降级

优先保留：

1. 家庭花园；
2. 爸爸鱼塘；
3. AI 房间。

可降级：

- 爷爷农场可变成花园里的一个入口卡片；
- 老街/胡同可先做成一张记忆背景图；
- 旅行区域可先用明信片节点代替完整场景。

### 7.2 AI 功能降级

优先保留：

1. 记忆卡片生成；
2. 漂流瓶问题生成；
3. 房间识别。

如果真实 AI 不稳定：

- 使用预设 mock JSON；
- 使用演示图片对应的固定结果；
- 保证地图节点照常生成。

### 7.3 后端降级

如果云端同步不稳定：

- 保留本地 mock 演示模式；
- 保留预设家庭和预设记忆；
- 用户上传失败时使用默认图片继续演示。

## 8. 功能冻结规则

建议里程碑：

| 日期 | 目标 |
|---|---|
| 6.15 | 第三人加入前，完成产品范围、资产规范、AI 输出格式、接手包 |
| 6.23 | 核心闭环跑通 |
| 6.30 | Beta 版本完成，可完整演示 |
| 7.8 | 功能基本冻结，进入修 bug 和包装 |
| 7.12 | 最终演示版本冻结 |
| 7.15 | 提交，不再大改 |

7 月 8 日后不再新增大功能，只允许修 bug、优化体验和准备提交材料。

---

## 9. 每个功能的准入判断

新增功能前必须回答：

1. 它是否服务家庭记忆？
2. 它是否促进家庭交流？
3. 它是否让花园/地图更像“记忆景观”？
4. 它是否能在 2 天内完成可演示版本？
5. 它是否会影响 P0 稳定性？

只有前 3 个问题至少两个为“是”，且第 5 个为“否”，才可以进入开发。
