# 21｜UI：漂流瓶问题面板 Bottle Panel

## 1. UI 作用

漂流瓶问题面板用于展示 AI 或家庭成员留下的温和问题，并收集用户回答。

它是 Family Garden 中促进家庭交流的重要界面。

---

## 2. 字段

| 字段 | 必须 | 说明 |
|---|---|---|
| question | 是 | 漂流瓶问题 |
| source | 可选 | AI / 某位成员 |
| answer_input | 是 | 回答输入框 |
| submit_button | 是 | 提交回答 |
| previous_answers | 可选 | 已有回答 |
| close_button | 是 | 关闭 |

---

## 3. 设计气质

漂流瓶面板应该像一张从瓶子里取出的纸条，而不是正式问卷。

关键词：

- 轻；
- 温和；
- 像纸条；
- 不像表单；
- 不给用户压力；
- 可以稍微有手写纸张质感，但不要真的使用难读字体。

---

## 4. 好问题示例

- “你们上一次一起出去玩是什么时候？”
- “小时候有没有一次和家人一起出门玩，让你现在还记得？”
- “家里有没有一顿饭让你一直记得？”
- “有没有一件小事，当时不觉得重要，现在回想起来很珍贵？”

---

## 5. 避免的问题

- “你和父母之间最大的矛盾是什么？”
- “你是不是觉得家人不理解你？”
- “你最讨厌哪个家庭成员？”
- “父母对你造成过伤害吗？”

比赛版本不做心理分析，也不引导冲突。

---

## 6. 交互流程

```text
点击漂流瓶
↓
打开问题面板
↓
用户阅读问题
↓
用户输入回答
↓
提交
↓
关闭面板
↓
场景中生成新记忆节点
```

## 8. 验收标准

1. 点击漂流瓶能打开面板；
2. 问题显示完整；
3. 用户能输入回答；
4. 提交后能关闭或显示成功；
5. 回答能保存；
6. 回答后场景中有反馈；
7. 手机横屏下输入框可用；
8. 文案不像问卷调查。
