# 22｜UI：上传面板 Upload Panel

## 1. UI 作用

上传面板用于让用户上传照片、房间图、明信片或文字记忆。它是 AI 记忆策展的入口。

---

## 2. 上传类型

比赛版本支持三类即可：

| 类型 | 用途 |
|---|---|
| 家庭照片 | 生成记忆卡片和地图节点 |
| 房间照片 | 生成个人房间 |
| 文字记忆 | 生成漂流瓶或记忆卡片 |

---

## 3. 面板字段

| 字段 | 必须 | 说明 |
|---|---|---|
| upload_type | 是 | photo / room_photo / text |
| file_picker | 是 | 选择图片 |
| preview | 是 | 图片预览 |
| text_input | 可选 | 文字补充 |
| submit_button | 是 | 提交 |
| cancel_button | 是 | 取消 |
| loading_state | 是 | 上传/AI 生成中 |
| error_state | 是 | 失败提示 |

---

## 4. 交互流程

```text
点击上传按钮
↓
选择上传类型
↓
选择图片或输入文字
↓
显示预览
↓
提交
↓
上传到存储
↓
创建 memory
↓
调用 AI
↓
显示记忆卡片或房间生成结果
```

---

## 5. 手机端注意事项

- 按钮要大；
- 选择图片后必须显示“已选择”；
- 上传中要有 loading；
- 上传失败要有明确提示；
- 如果手机浏览器不支持上传，要走 fallback；
- 不要让用户选择后没有反馈。

---

## 6. 错误提示

推荐文案：

- “图片暂时没有上传成功，可以换一张再试。”
- “AI 暂时没有整理成功，我们先为你生成一张示例记忆卡。”
- “当前浏览器可能不支持上传，请尝试在浏览器中打开。”

避免：

- “Error 500”；
- “Upload failed”；
- 技术性报错直接显示给用户。

## 8. 验收标准

1. 用户能打开上传面板；
2. 能选择图片；
3. 选择后能看到预览或文件名；
4. 能提交；
5. 上传失败有提示；
6. AI 失败有 mock 兜底；
7. 手机横屏下可操作；
8. 不影响主场景交互。
